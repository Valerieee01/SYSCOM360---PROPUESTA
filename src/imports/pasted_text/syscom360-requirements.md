Prompt mejorado para Syscom360

Quiero diseñar y desarrollar un aplicativo empresarial llamado Syscom360, enfocado en la gestión integral de empresas, con una arquitectura modular, moderna, escalable y profesional. El sistema debe tener una interfaz elegante, intuitiva, automatizada, rápida y de alta calidad visual, con una experiencia de usuario tipo software ERP moderno.

La plataforma debe permitir manejar múltiples módulos empresariales, entre ellos:

Transporte

Contabilidad

Nómina

EDS

Otros módulos complementarios que puedan crecer a futuro

Objetivo general del sistema

El objetivo de Syscom360 es centralizar en una sola plataforma todos los procesos operativos, administrativos, contables y documentales de una empresa, permitiendo trazabilidad, automatización, control, reportes y facilidad de uso.

El sistema debe verse como un producto corporativo premium, con:

Diseño moderno tipo dashboard

Menú lateral con módulos

Tarjetas de resumen con indicadores

Tablas limpias con filtros avanzados

Formularios elegantes y fáciles de diligenciar

Colores corporativos sobrios y profesionales

Componentes visuales modernos

Alertas, notificaciones y estados visuales claros

Automatizaciones en procesos repetitivos

Validaciones inteligentes en formularios

Flujo de trabajo eficiente para cada documento o proceso
