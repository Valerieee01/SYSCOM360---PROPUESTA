Campos requeridos para ORDEN DE CARGUE
1. Datos Básicos

Información principal del documento.

No. Orden

Cia (Compañía)

No. Pedido

Cia Pedido

Tipo de operación

Tipo de ruta

Lugar pago flete

Estos datos normalmente se heredan del pedido o se autocompletan.

2. Información del Remitente

Remitente (Nombre o NIT/Cédula)

NIT / Cédula del remitente

Sede origen

Dirección sede origen

Funciones esperadas:

Autocompletado del remitente

Carga automática de sedes

3. Información del Destinatario

Destinatario (Nombre o NIT/Cédula)

NIT / Cédula destinatario

Sede destino

El sistema debería completar automáticamente:

dirección destino

ciudad destino

4. Propietario de la Carga

Generador de carga
(Ejemplo: Remitente / Propietario)

Identificación propietario

Esto se usa para reportes al RNDC.

5. Ruta

Ruta

Debe poder seleccionar:

ruta registrada

ruta sugerida por origen y destino

6. Información del Vehículo

Vehículo (Placa)

Remolque (Placa)

Nombre conductor

Campos adicionales:

Documento conductor

Nombre conductor completo

El sistema debería:

autocompletar conductor al seleccionar vehículo

validar estado del vehículo

7. Detalle de la Mercancía

Información obligatoria del transporte.

Código de la mercancía

Descripción de la mercancía

Peso neto

Unidad de medida

Código INVÍAS

8. Detalle logístico adicional

Campos adicionales de carga:

Unidades

Volumen

Unidad de medida volumen

Referencia 1

Empaque

9. Información de mercancía peligrosa (si aplica)

Naturaleza

Código UN

Descripción residuo peligroso

Corrientes de residuos peligrosos

Desagregación de corrientes

Esto se usa para regulación de transporte de materiales peligrosos.

10. Tiempos

Cita para cargue

Cita para descargue

Formato esperado:

dd-mm-aaaa hh:mm
11. Información adicional

Comentarios

12. Información del sistema (automática)

Estos campos normalmente no se editan:

Fecha creación sistema

Usuario creación

Estado orden

Resumen de campos obligatorios (mínimos)

Para cumplir la regla de 3 clics en Syscom360, la orden podría requerir solo:

No Pedido

Remitente

Destinatario

Ruta

Vehículo

Conductor

Descripción mercancía

Peso

Cita cargue

El resto se autocompleta.
